Trajetória de um site.

nessa página irei explicar detalhes sobre a trajetória de um site.

➥Validação e Registro do Domínio:

Nessa etapa o usuário deve solicitar um "link". E logo em seguida a empresa que recebeu a solicitação deve consultar se já há um registro com esse nome, caso haja o "link" do usuário deve ser reservado em um banco de dados global.

OBS: Caso não tenha o "link" disponível, o usuário deve optar por outro nome.

➥Configuração da Hospedagem:

Nessa etapa o usuário irá "emprestar" uma parte de um servidor, isso significa, contratar um servidor de hospedagem e receber um endereço de IP público.

➥Apontamento DNS:

Os domínios utilizam letras para facilitar o acesso humano, já para a internet a navegação é feita por números(IPs). Também podendo alterar os Nameservers.

É criado um tipo de registro na tabela DNS que "conecta" o nome do site para o endereço IP do servidor. Logo após inicia-se a propagação, onde essa informação é levada para toda a internet do mundo.

➥A Requisição do Usuário:

O site já está no ar e quando um usuário procurá-lo o servidor irá devolver o IP em milissegundos

➥Processamento e Entrega da Página:

Com o IP, o navegador abre uma conexão via HTTP/HTTPS para o servidor web receber a chamada, processar as instruções e passa a informações para o front-end
